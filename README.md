# Blockforge
یه اپلیکیشن همه منظوره جهت بازسازی کامل برنامه ها برای کار های مختلف است که درحال حاضر توسط noxarys entertainment درحال توسعه است.

البته بگوییم که برنامه هنگام نصب فایل های مورد نیاز خود را نصب میکند و اماکان ذخیره سازی محلی بدونه نصب هم وجود دارد.

اگر میخواهید فایل های اپ را کامل حذف کنید باید وارد داکیومنت ها در بخش فایل ها شوید.سپس میتوان پوشه Block forge را دید که قابل حذف است.این پوشه مربوط به ذخیره سازی استخراجی ها و ... است که بدونه آن هم برنامه اجرا میشود و نیاز ضروری ای ندارد.

از جمله ویژگی های نسخه اپ بلاک فورج:


● فشرده سازی و استخراج اسناد 📁

● قدرتمند سیستم رمزنگاری جهان 🔑

● اعلان پیشرفته 🗨

● یادداشت 📝

● ماشین حساب پیشرفته 🧾

● موزیک پلیر 🎶

و غیره..


# settings

بلاک فورج دارای تنظیمات مختلف برای بهبود کاربری است.

میتوان برنامه را به دو زبان فارسی و اینگیلیسی (enlish beta ) ترجمه کرد.

بلاک فورج شامل دو تم Dark و Light است که قابل تنظیم است.

جهت آسان تر شدن پیدا کردن ابزار ها (Tools) قابلیت short cut را اضافه کردیم که در تنظیمات قابل دسترس است.

امکان حذف و تعمیر فایل های ساخته شده در داکیومنت وجود دارد که دسترسی کامل را به کاربر می‌دهد.

تنطیمات کامل Mrar و ... در اختيار شماست.

علاوه بر آن سیستم log هرگونه ارور نرم افزاری را نمایش میدهد.

# نکات امنیتی

ممکن است برنامه توسط سیستم امنیتی ها مورد اخطار قرار بگیرد زیرا برنامه به دلیل وجود نیاز های نرم افزاری جهت اجرای نرم افزار مورد شک قرار بگیرد ، تیم ما امنیت شما را تضمین میکند 😁

هرگونه اشتراک رمز در فشرده سازی های مهم فایل ها غییر امنیتی و موجب لو رفتن اطلاعات فایل میشود ، پس از اشتراک رمز عبور فایل های مهم خودداری کنید.

فشرده سازی اختصاصی ( mrar ) با استفاده از rar و رمز نگاری دو لایه 256 بیتی + کلید امنیتی ۶۴ مگابایتی که با بهره گیری از AES قوی ترین کلید امنیتی را میسازد.

برنامه هیچ گونه apk دانلود نمیکند به جز آپدیت برنامه پس اگر فعالیت مشکوک دیدید گزارش دهید.

# سوالات

چگونه فایل های اضافه را حذف کنیم ؟

میتوان فایل های اضافی که در داکیومنت قرار دارن که هنگام اجرای اولیه برنامه نصب میشوند را میتوان از برنامه : setting/storage/delet all whole Blockforge folder in document

یا با باز کردن پوشه :
document/blockforge
آن را حذف کرد.


چگونه زبان برنامه را عوض کنیم؟

اول وارد setting میشویم و سپس وارد زبان برنامه میشویم و زبان را انتخاب میکنیم.


چگونه تم برنامه را عوض کنیم؟

وارد setting شده و سپس thems.


چگونه ابزار ها را سریع تر دسترسی داشته باشیم؟

وارد setting شده و سپس shortcut و انتخاب کنید چه ابزاری را میخواهید. ابلته میتوانید از هدر برنامه ابزار خود را سرچ کنید.
